# CS250_Software_Development_Lifecycle

## Sprint Review and Retrospective
This repository contains my CS 250 Sprint Review and Retrospective. This project reflects on what I learned about Agile and Scrum practices throughout the course. It includes user stories, Scrum roles, communication, testing, working as part of a development team, and handling changes. 

## Reflection
### How do I interpret the user needs and implement them into a program? How does creating "user stories" help with this?
I interpret the user needs by determining what it is the customer expects from the program and what features work best for them, then I can break them into smaller requirements which can make it easier to develop and test. Creating user stories help turn larger items into smaller features that is easier for the team to understand, prioritize, and complete. With the SNHU Travel project the user stories helped connect the customers expectations with what work needed to be developed. 

### How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?
My approach to developing programs is to work step by step reviewing the requirements and dividing the work into smaller requirements. Then build the program in smaller pieces and test it before moving forward. If there is a problem that occurred I will review my changes and make the corrections as needed. For my future developments I would like to use Sprint Planning, backlog refinement, regular communication, continuous testing, and sprint retrospectives since the project can help keep the project organized and make changes when they are needed. 

### What does it mean to be a goo team member in software development?
To me a good team member is someone who is willing to communicate, be dependable, and accept feedback and listen to other ideas. Also completing your own work while still being aware of how it connects to the work of other team mates. Software development is a team effort which means with the support one another and share information when other person needs the help for problems. The Scrum activities in this course helped me see the importance in communication and collaboration in completing the project successfully.
